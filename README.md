# Laravel CRUD de Usuarios

Este proyecto consiste en una aplicación funcional para la gestión de usuarios (Crear, Leer, Actualizar y Eliminar), desarrollada con el framework Laravel 11. El objetivo principal es demostrar el manejo de rutas, controladores, modelos y validaciones bajo la arquitectura MVC.

## Tecnologías Utilizadas

* Framework: Laravel 11
* Frontend: Blade Templates y Bootstrap 5
* Base de Datos: MySQL / MariaDB
* Entorno de Desarrollo: Laravel Herd, Warp Terminal

## Funcionalidades

* Listado general de usuarios con recuperación de datos desde la base de datos.
* Formulario de creación con reglas de validación de datos.
* Edición de registros existentes con persistencia de datos.
* Eliminación de usuarios.
* Mensajes de confirmación de operaciones exitosas.
